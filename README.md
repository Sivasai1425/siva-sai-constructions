# Siva Sai Constructions — House Calculator

Upload `index.html` and `manifest.json` to the root of the GitHub Pages repository.

Features:
- Plot dimensions, road width, facing and building configuration
- Automatic preliminary AP Table 17 setback selection
- Vastu and room requirements
- CAD-style preliminary 2D floor-plan output
- Detailed material and cost-breakdown quotation
- 3D/9-panel AI architectural presentation prompt
- Optional Render backend for generated 3D presentation image

Setbacks are a planning aid, not sanction certification. Verify current GVMC master-plan/zonal rules, road widening and site-specific conditions with a qualified professional.


## Vastu mode
The calculator now prioritizes the user's requested Vastu-oriented zoning:
- South-West: master bedroom
- Master bedroom: attached toilet
- North-East: pooja room / lighter open zone
- South-East: kitchen
- North-West: staircase
- Living: good ventilation and daylight

These are traditional planning preferences. They do not override structural engineering, fire safety, accessibility, ventilation/daylight requirements, or statutory building rules.
