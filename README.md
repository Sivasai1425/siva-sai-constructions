# Siva Sai Constructions - Home Package Website

A responsive GitHub Pages-ready website inspired by the supplied premium construction package design.

## Features

- Premium hero landing section
- Value / Premium / Luxury package cards
- Tap a package to open detailed inclusions
- Separate Construction Calculator button
- Calculator updates instantly from built-up area and package rate
- Mobile responsive layout
- No backend required
- GitHub Pages compatible

## Change package prices

Open `script.js` and edit:

```js
rate: 2199
rate: 2499
rate: 2799
```

## Change company name

Edit the text in `index.html`.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/root`.
6. Save. GitHub will provide your website URL.

## Important

The calculator is an indicative construction estimate. Update the rates and package inclusions to match your actual BOQ, brands, location, GST and project terms.
