# Siva Sai Constructions AI House Planner

Upload the contents of this `frontend` folder to the root of your GitHub Pages repository.

## Important
This frontend does NOT contain an OpenAI API key. The API key belongs only in the backend environment variables.

## GitHub Pages
1. Upload `index.html` and `manifest.json` to the repository root.
2. Open Settings → Pages.
3. Set Source to Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Save.
