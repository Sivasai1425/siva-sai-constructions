# Siva Sai Constructions | Smart House Planner

## GitHub Pages setup

Upload these files to the **root** of your GitHub repository:

- `index.html`
- `manifest.json`
- `README.md`

Then open **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

## Included in the final index.html

- Plot width/depth, road width and facing
- Preliminary AP/GVMC planning setback calculator
- Vastu-oriented planning preferences
- 2/3/4 BHK floor-plan selection
- Editable room dimensions in feet and inches
- Setback overrides
- Dimension-aware 2D floor-plan visualization
- Locked room dimensions shown in the generated plan
- Basic geometry conflict detection for locked rooms
- Feet-and-inches architectural dimensions
- Exact CAD-style 2D floor-plan AI prompt
- 3D / 9-panel AI presentation prompt
- Detailed construction quotation
- Materials and specifications
- Professional print / PDF output
- Optional Render backend hook for generated visual output
- PWA manifest for Android home-screen installation

## Important

The 2D planner is a conceptual planning tool. Locked room dimensions are used to size the corresponding rooms in the visualization and are checked for footprint/overlap conflicts. Final architectural, structural, electrical, plumbing, fire-safety and statutory drawings must be verified by qualified professionals and applicable local regulations before construction.
