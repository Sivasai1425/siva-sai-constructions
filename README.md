# Siva Sai Constructions - Landing Page V2

This version uses the supplied reference image's **exact building image** as the hero visual and package-card image, while replacing the reference advertisement copy with Siva Sai Constructions content.

Files:
- index.html
- style.css
- script.js
- reference-building.jpg

Features:
- Reference-style premium landing page
- Value / Premium / Luxury packages
- Click/tap package details
- Full house planning calculator
- Plot dimensions and facing
- Road width
- G / G+1 / G+2
- Stilt + G / G+1 / G+2
- BHK
- Parking
- Lift, OTS, balcony and smart-home options
- Setback inputs and Auto Setbacks
- Vastu planning options
- Staircase type
- Automatic footprint and built-up area estimate
- Package rate calculation
- Copy floor-plan prompt
- Copy quote summary
- Mobile responsive

GitHub Pages:
Upload all four files to a repository and enable Settings → Pages → Deploy from branch → main/root.
